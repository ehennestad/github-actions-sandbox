# Live export demo

This live script exists to test whether `export` with `Run=true` works headlessly on a GitHub Actions runner, and whether the resulting markdown can be committed back automatically.

# Text output

A value assigned without a semicolon is captured as output:

```matlab
answer = 6*7
```

```matlabTextOutput
answer = 42
```

# Output from a function on the path

`ghas.helloWorld` lives in this repository's `code` folder.

```matlab
ghas.helloWorld()
```

```matlabTextOutput
hello world
ans = "hello world"
```

# The MATLAB release that produced this file

If the markdown is regenerated by the action, this line changes with the runner's MATLAB.

```matlab
disp("Exported with " + version('-release'))
```

```matlabTextOutput
Exported with 2026a
```
